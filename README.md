# Portafolio — Junior

Portafolio web personal construido con **HTML**, **CSS** y **JavaScript** vanilla. Diseñado para ser minimalista, responsive y listo para desplegar en GitHub Pages.

## Secciones

- **Inicio** — Presentación, rol, botones a proyectos y contacto
- **Sobre mí** — Descripción, estudios (UPN), stack principal
- **Proyectos** — Cards con Hotel Nova y Dual Search
- **Skills** — Grid de tecnologías con iconos (Devicon)
- **Contacto** — Email, GitHub, LinkedIn, descarga de CV

## Tecnologías usadas

- HTML5 semántico
- CSS3 con variables y Flexbox/Grid
- JavaScript vanilla (Intersection Observer, menú hamburguesa)
- Google Fonts (Space Grotesk + Inter)
- Devicon CDN para iconos

## Despliegue en GitHub Pages

1. Sube este repositorio a GitHub
2. Ve a *Settings > Pages*
3. Selecciona la rama `main` y carpeta `/ (root)`
4. Guarda — tu sitio estará disponible en `https://jun1or11.github.io/Portafolio/`
